# Buenas News

Blog de notícias desenvolvido com foco em práticas educativas de HTML5 e CSS3, utilizando tags semânticas e responsividade.

## 📚 Sobre o Projeto

O Buenas News é um blog fictício de notícias, criado para fins educativos. O principal objetivo é demonstrar o uso correto de tags semânticas do HTML e aplicar estilos com CSS, incluindo técnicas de responsividade para garantir uma boa experiência em dispositivos móveis.

Acesse a versão online: [Buenas News no GitHub Pages](https://jotaveeo.github.io/BlogDeNoticias-Site/)

## 🚀 Funcionalidades

- Estrutura semântica com HTML5
- Layout responsivo (desktop e mobile)
- Design moderno e limpo com CSS3
- Conteúdo simulado de notícias

## 🖥️ Tecnologias Utilizadas

- HTML5 (com ênfase em tags semânticas)
- CSS3 (responsividade, Flexbox, etc.)
